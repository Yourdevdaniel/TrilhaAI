# TrilhaAI

> 🚧 **Em desenvolvimento.** Projeto da faculdade de Ciência da Computação & Engenharia de Software, feito na disciplina
> Engenharia de Requisitos e Modelagem de Software. O código ainda não foi publicado.

Software que usa Inteligência Artificial para montar **roadmaps de estudo**. A pessoa define um
objetivo (por exemplo, "conseguir o primeiro estágio em back-end") e o TrilhaAI devolve os passos
na ordem certa, com recursos gratuitos para cada etapa.

## O que ele vai fazer

- Receber o objetivo e o nível atual da pessoa
- Gerar uma trilha de estudo em etapas
- Indicar recursos gratuitos (cursos, documentação, vídeos) para cada etapa
- Acompanhar o progresso
